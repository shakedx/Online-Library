# Спецификация Online Library

## Назначение

Онлайн-библиотека содержит собственный каталог. Пользователь может зарегистрироваться, читать загруженные TXT-книги, вести личные списки и оставлять отзывы.

## Роли

- Гость видит каталог, карточки книг и отзывы.
- Пользователь также читает TXT, использует личные списки и оставляет отзывы.
- Администратор также создаёт, изменяет и удаляет книги, загружает TXT.
- Роль администратора назначается локальной командой существующему аккаунту.

## Технологии

- Node.js, JavaScript, Express и PostgreSQL;
- React, JavaScript/JSX, Vite, React Router и CSS Modules;
- подписанная HttpOnly cookie и CSRF-защита;
- локальная папка для TXT при разработке и private Vercel Blob после размещения.

## База данных

Основные таблицы: `users`, `books`, `reviews`, `favorites`, `reading_list`, `reading_history`. Таблица `app_migrations` хранит список применённых SQL-миграций.

Email и ISBN уникальны. Один пользователь может оставить книге только один отзыв. Оценка — целое число от 1 до 5, комментарий необязателен.

## TXT

- Загружается один непустой `.txt` в UTF-8.
- Имя файла создаёт сервер, а в БД хранится путь внутри хранилища.
- Чтение TXT не добавляет книгу в историю автоматически.
- Максимальный размер задаётся через `MAX_BOOK_SIZE_BYTES`.
